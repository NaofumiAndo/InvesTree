# 🌳 育てる木 — ポートフォリオの木 プロトタイプ

残高という「数字」の隣に、ポートフォリオの姿そのものを映した**一本の木**を表示するアプリのプロトタイプです。
木の形を一目見るだけで、**長く続けているか / 分散できているか / 年齢に合ったリスクか**が直感的に伝わることを目指しています。

## 使い方

ビルド不要です。`index.html` をブラウザで開くだけ。

```
open index.html        # macOS
xdg-open index.html    # Linux
```

## このプロトタイプでできること

- **5人のプロフィール切り替え** — 保有商品・積立期間・年齢がバラバラな5人を上部のボタンで切り替え、木の形がどう変わるかを比較できます。
  1. 🌱 **若者・オルカンのみ**（24歳/2年/全世界株100%）— 分散済みでそよ風の若木
  2. 🍂 **高齢者・個別株のみ**（68歳/36年/1銘柄100%）— ひょろ高く、暴風でしなる頼りない幹
  3. 🌳 **育成中バランス型**（38歳/9年/株+債券+REIT）— 二股の健やかな木（仕様書の例）
  4. 🌲 **退職前・理想バランス**（60歳/31年/株債50:50+現金）— 左右対称の大樹
  5. 🪙 **暗号資産偏重・頭でっかち**（32歳/5年/その他が大半）— 枝だけ茂って幹がスカスカ
- **パラメータ・スライダー** — 年齢・積立年数・株式の分散度・株/債券/その他/現金の量を動かすと、木がリアルタイムに変化します（「カスタム編集中」表示に切り替わります）。
- **木のタップ解説** — 幹・枝・葉・根をクリックすると、現在の状態に応じたやさしい解説バブルが出ます。

## 中核メタファー（実装している対応関係）

| 木の要素 | 投資の概念 | 実装 |
|---|---|---|
| 樹高 | 積立継続年数 | 年数で飽和的に成長（芽→若木→大樹） |
| 株の幹の太さ | 株式内の分散度 | 金額加重 `log10(実質銘柄数)`。1銘柄=細い葦／分散=太く木質化 |
| 幹の二股化 | 債券の組み入れ | 債券があると2本目の幹が育つ |
| 二股の太さ比率 | 株式 : 債券 配分 | 50:50で左右対称＝最も美しく安定 |
| 足元の鉢植え | その他資産（REIT/金/暗号資産等） | 木とは別物の脇役。少量は彩り、過大だと鉢が増えて本体より目立つ警告に |
| 風の強さ | 年齢に対するリスクの過不足 | `gap = 実際の株式% − target(110−age)`。過剰なほど暴風 |
| 根の深さ | 現金・生活防衛資金 | 深い根ほど強風に耐える土台 |

## 技術メモ

- 単一の `index.html`（依存なし・バニラJS + SVG）。
- 木は素材の差し替えではなく**パラメトリックに生成**（procedural）。データモデル（`PROFILES`）→ 生の状態（`profileToState`）→ 描画パラメータ（`deriveTree`）→ SVG（`buildTree`）という流れ。
- データソースは現状モックJSON。将来、証券口座API・手入力フォーム・CSV取込に差し替え可能な構成。

> 元の企画プロンプトの §2〜§4 の体験目標（長期積立・分散・年代別リバランスを、文章を読まずとも形だけで感じ取れる）を検証するための土台です。
